# Route Mission Execution

This conditional owner supplies execution quality and economy evidence to agent routing. It does not
own lifecycle, lane admission, user model consent, independent review, acceptance, or effects.

Choose the lowest route that meets the real consumer, evidence completeness, oracle, safety,
permission, authority, and effect floors. Missing cost/model telemetry invalidates only that
comparison: retain the authorized main or host-default route and mark the alternative `unavailable`.
Never route by quota.

Evidence maturity is `contradicted`, `declared`, `reachable`, `dynamic`, or `stable`: configuration or
a static call path reaches at most `reachable`; one bound success may reach `dynamic`; representative
positive, negative, and recovery cases are required for `stable`.

A `fast_builder` leaf is admitted only when Origin, exact paths, owner, boundary, replacement bytes or
mechanical transform, oracle, safe checks, one writer, and Stop are frozen, with no remaining design,
wording, schema, authority, safety, dependency, or effect choice. Observe its configured model/effort;
unavailable capability may fall back once to standard main before dispatch, while any uncertain or
failed attempted dispatch stops without retry.

Compare models/effort only on naturally occurring equivalent tasks with the same consumer, inputs,
protocol, permissions, tools, environment, and quality floor. Record quality, latency, exposed tokens,
loaded context, communications, correction/recheck, and failures as observed or unavailable. Prefer
an observed Pareto improvement among routes that pass every quality floor; one sample is not a durable
ranking. Do not create a benchmark, task, test, typo, or permanent model table to manufacture evidence.

Candidate work remains one coherent consumer slice with one semantic writer. A conditional native
test hook may be used when a maintained oracle materially shortens correction; repository-specific
test processes are never a default. Test evidence that can change the candidate routes to
`../verification/verification-test-integrity-policy.md`.
