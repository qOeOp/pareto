# Lifecycle Quality Assurance

Load QA only when a lifecycle-boundary observation indicates a mismatch or the user explicitly
complains that this Skill behaved incorrectly. QA owns signal classification, evidence binding,
single-owner routing, and closure verification. It does not repair, schedule tasks, retain custody,
scan global history, aggregate recurrence, route models, or own CI/GitHub details.

## Classify one signal

Bind the failed relationship, current authority, immutable evidence locator, impact, and one native
owner. Choose one outcome:

| Outcome   | Decision                                                                                     | Output                                             |
| --------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| block     | a required transition/effect condition is false or its required evidence is unavailable      | freeze that boundary and route the exact predicate |
| route     | a real defect belongs to another existing owner without invalidating unaffected work         | send one locator-bound finding to that owner       |
| advisory  | current obligations pass and evidence supports a bounded improvement                         | proposal with benefit, cost, risk, and falsifier   |
| no-signal | evidence supports alignment, is non-required/insufficient, or is a controlled false positive | no QA artifact, task, or communication             |

Unknown evidence blocks only when the current decision requires it. Counts, delay, traffic, wording,
or preference alone are no-signal.

## Route and close

Route by root authority, not symptom location:

- planner: Outcome, scope, authority, acceptance, Plan, or structural replan;
- orchestrator: task identity/custody, DAG release, Hub observation, recovery, or communication;
- executor: candidate implementation or Plan coverage;
- verifier: evidence integrity, oracle, independence, provenance, or consumer coverage;
- delivery: publication, exact-head checks, conversations, freshness, mergeability, or effects;
- optimizer: patch pressure, duplicate authority, missing consumers, implementation/document drift,
  repeated rework, communication/context inflation, or integrated behavior regression.

QA never copies the routed owner's rules. The native owner repairs through the existing lifecycle.
Closure means rerunning the scenario that produced the signal and binding its result to the same
relationship. No-signal or unavailable evidence creates no recurrence claim or persistent record.

## Critical floor

The golden defect floor includes lost work or task custody, wrong conditional activation, duplicate
authority/effects, candidate/evidence identity drift, missing required evidence, skipped owner
loading, false terminal claims, repeated unchanged polling/retry, and user-reported Skill behavior
regressions. Preserve the direct evidence and fail closed at the affected boundary.

An anti-entropy signal routes to Optimization when evidence shows repeated patching, duplicated
authority, an unconsumed owner, documentation/implementation drift, or repeated rework/communication
that changes no decision. File size or untidy prose alone is no-signal.
