# Run the Plan Design Loop

Load this reference only when a material decision can change authority, owner, architecture,
verification, reuse, or another hard-to-reverse choice. The main agent owns all decisions and Plan
admission; this reference creates no durable design state, second Spec system, or effect authority.

## Choose the smallest decision depth

- **Direct:** current authority and consumer close a safe, reversible choice. Stay in the kernel.
- **Bounded:** inspect only the few reversible material choices still open.
- **High-consequence:** inspect every material frontier for cross-owner, public-contract, safety,
  authority-migration, or hard-to-reverse work.

Unknown consequence or authority cannot use Direct. Deepen only the affected frontier; prose, time,
turns, and option counts never admit a Plan.

## Discover and deliberate

Start from the Frame, no-change counterfactual, current owners, real consumer, and acceptance. Use the
cheapest repository or consumer probe that can distinguish each material path. Load [decision
evidence](planning-decision-evidence.md) only when bounded history, ambiguity, or current external
facts can change that decision.

For Bounded or High-consequence work, name at most three architecture-killing assumptions: failures
that invalidate Outcome or consumer, change owner or lifecycle, cross a critical floor, or make the
leading route unsafe or uneconomic. Rank qualitative decision value by error likelihood, avoidable
consequence and irreversibility against probe cost; invent no scores or telemetry. Before broadening
the candidate, test the leader with the cheapest decision-changing vertical falsifier.

For each authority, choose one disposition: reuse it; repair or migrate it while deleting its
superseded path; create it only when no current owner can express the contract; or keep the decision
Mission-only when no stable consumer needs repository state. A requested Spec, template, or test does
not itself prove a Spec consumer.

Challenge the requested mechanism as one candidate. Compare only materially different credible
paths, including no change, rollback, deletion, direct wiring, and reuse. Test the strongest objection
and identify the observation that would invalidate the leading route. Ask the user only for a fact,
preference, or effect authority they alone own and that changes the Plan; bundle the smallest related
questions and recommend a route when evidence supports one.

## Resolve reuse before building

Inspect local owners, history, dependencies, configured integrations, and adopted upstreams first.
When external prior art can change the choice, search broadly enough to find credible alternatives,
then verify only the shortlist's compatibility, maintenance, license, source behavior, tests,
operational cost, and failure modes. Prefer `adopt`, then `adapt`, then `reference`; build only when
evidence rejects the strongest reusable path.

Use primary sources and current behavior. Popularity, summaries, and generated answers are leads, not
authority. Stop when decision-changing claims are supported or explicitly unavailable and another
distinct query is unlikely to change the shortlist. Use one fresh read-only researcher only when the
unknown candidate set or source volume would displace main contract/candidate context. Its packet
binds the Frame, one question and consequence, bounded scope, safe locators or terms, required return,
and a finite Stop. The main agent reopens decisive sources and owns the decision.

## Admit one current Plan

Admit only the smallest vertical candidate that reaches a real consumer and exposes the highest-risk
assumption. Fold setup, configuration, documentation, verification, and cleanup into the slice that
consumes them. Put only final Plan-changing decisions in the existing Plan projection:

- selected authority and immutable locator, or `none` with basis;
- solution/test authority and Spec disposition only when a named stable consumer needs them;
- superseded paths removed by the same slice;
- unresolved consequences, evidence status, and the Stop for each dependent decision;
- `revalidate_after` for authority, consumer, candidate, or component changes that invalidate it;
- the earliest observation that forces `replan` or `reframe`.

Use disposable code only for the cheapest decisive probe; label it `throwaway`. Before another probe,
close it: failure deletes its executable path, flags, dependencies, result-specific tests and duplicate
prose, reverting changes whose only consumer was the probe. Retain one compact decision record; retain
reusable code only for a named independent current consumer. Missing closure freezes the next probe.
Success does not promote it: build the smallest production slice and update only surviving contracts,
tests and decisions.

Keep facts at their nearest enforceable owner: types constrain states, code expresses behavior, tests
observable promises, comments only rationale code cannot express, and documents cross-boundary
contracts, user or operational guidance, and architectural decisions. Link rather than copy; retain no
duplicate implementation truth.

Do not retain exploration logs, option diaries, parallel Specs, or a second packet/schema. Every final
decision needs a downstream consumer; unknown essential evidence freezes only its dependent decision.
The sole Execute-admission result is the complete current Plan projection. Replace it and the current
checkpoint when a material decision changes; never append corrections to stale Plan prose.

## Route later evidence at the earliest boundary

- **candidate-local:** the admitted owner, path, responsibility, boundary, and oracle still hold; fix
  only the execution omission.
- **replan:** one of those Plan facts fails, an omitted decision changes the candidate, or the same
  causal root keeps a non-shrinking candidate under the same Frame.
- **reframe:** Outcome, consumer, scope, non-goal, effect authority, intent/acceptance authority,
  acceptance, Origin, or Stop changes.

Checks, diff size, prose volume, or revision count never select the route. Bind the observation to the
first changed decision, replace the Plan after `replan`, and clear it after `reframe` until a new Plan
is admitted.

`replan` or `reframe` only when an observation changes a Plan or Frame field, respectively. A leaf
difference is candidate-local only while its admitted owner, path, responsibility, boundary, and
oracle hold; otherwise route at the first changed field. No decision-changing observation means Stop.

## Make slices falsifiable

Use independent slices only when their candidate or Stop must be independently rejectable. Each slice
names its consumer, dependency, cheapest decisive check, and earliest `replan`/`reframe` observation.
For a failing check, reproduce the exact failure, localize one cause, make the smallest coherent
correction, and rerun that check plus the narrowest relevant regression. Convergence follows causal
closure, not attempt counts.

Before expanding a shared skeleton, test it through one materially different consumer or
failure/recovery slice; a near-duplicate happy path is not independent evidence. Preserve any critical
invariant demonstrated by relevant consumers with the smallest executable fitness function in an
existing owner or gate. Create no framework, downgrade no low-frequency critical path, and claim no
value beyond the observed boundary.
